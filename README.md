# factory-management-system
Contemporary Programming Group project

# description
SmartTech Manufacturing Ltd. operates a semi-automated factory that manufactures electronic and electrical products.
The factory uses production machines, conveyor systems, sensors, production lines, operators and maintenance
personnel. Management requires a customized Factory Automation Management System to improve the recording and
monitoring of factory operations.
The system will maintain information about production machines, products, production orders, operators/technicians,
machine status, production output, maintenance activities and production costs.

# system Login
The system is restricted to authorized personnel. The user must enter a valid username and password and is allowed a
maximum of three login attempts. After three unsuccessful attempts, the program must display an appropriate message
and terminate.
